# AntiphishingRD Blacklist

Repositorio de código abierto dedicado a recopilar, verificar y mantener un registro actualizado de dominios, URLs y recursos maliciosos utilizados en campañas de phishing e ingeniería social dirigidas a usuarios en la República Dominicana.

## Características
- **Monitoreo Localizado:** Enfoque en amenazas y dominios fraudulentos que imitan marcas, instituciones y servicios populares en el país.
- **Actualizaciones Constantes:** Alimentado y sincronizado para mitigar vectores de ataque emergentes.
- **Fácil Integración:** Diseñado para ser consumido por herramientas de seguridad, servidores web, firewalls o scripts de mitigación (compatible con Nginx, Cloudflare, etc.).

## Uso
Esta lista puede ser utilizada por administradores de sistemas y profesionales de ciberseguridad para bloquear de manera preventiva el acceso a sitios web fraudulentos y proteger la infraestructura digital.
